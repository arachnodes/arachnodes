## About

I am an anonymous web developer focused on building practical, real-world applications from scratch.

My work is primarily front-end, while each project helps me improve my PHP, JavaScript and database skills. I prefer learning the foundations and understanding how things work beneath the surface rather than relying heavily on frameworks.

## Current Focus

- Building complete applications from the ground up
- Strengthening PHP, JavaScript and database fundamentals
- Writing cleaner, more maintainable code
- Learning through projects, experimentation and iteration
